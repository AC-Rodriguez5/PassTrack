# 🔐 PassTrack

> A secure password management application designed to help users store, organize, and access their credentials safely and efficiently.

## 📖 Overview

PassTrack is a cross-platform password management application developed using **React Native (Expo)**. It provides users with a secure and convenient way to manage their digital credentials while promoting better password organization and accessibility.

The application allows users to securely store login information for multiple accounts, categorize saved credentials, and quickly retrieve passwords whenever needed. PassTrack is designed with a clean and user-friendly interface, making password management simple for both personal and professional use.

---

## ✨ Features

- 🔑 Secure user authentication
- 📂 Organize passwords by category
- 🔍 Search stored credentials
- ➕ Add, edit, and delete password entries
- 👁️ Toggle password visibility
- 📱 Responsive mobile interface
- 🎨 Modern UI built with NativeWind
- 🔒 Secure storage implementation *(ongoing)*

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/AC-Rodriguez5/PassTrack.git
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npx expo start
```

Open the application using:

- Expo Go (Android/iOS)
- Android Emulator
- iOS Simulator
